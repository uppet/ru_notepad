# ru_notepad app icon

Original artwork generated with OpenAI's built-in image generation tool on 2026-10-16 for this project. No existing app logo or external reference image was supplied for the selected artwork.

- `app-icon.png`: unmodified generated high-resolution RGBA source with transparent background.
- `app-icon.ico`: Windows icon container derived only from the PNG, containing 16, 20, 24, 32, 40, 48, 64, 128, and 256 px variants. Pillow performs the ordinary resampling and format packaging; it does not create or redraw the artwork.
- Design: compact open book, teal and pale-paper panels, indigo contour, amber bookmark, and four broad writing strokes. No text or borrowed editor branding.

## Generation prompt

```text
Use case: logo-brand
Create a single original production-ready Windows app icon for the text editor ru_notepad. The mark is a minimal compact open notebook with two broad rounded page panels joined by a shallow V fold. Bold indigo outer contour, teal left page, pale cool-white right page, one small amber bookmark. Only two broad horizontal writing strokes per page. Precisely flat vector-like visual style, solid clean colors, extremely simple shape construction, no textures, no grain, no gradients, no glow, no soft shadows, no reflections. All shapes have crisp smooth antialiased contours. Distinctive yet understated, instantly legible at 16 pixels.
One centered icon only, upright front view, square canvas, icon takes 76 percent of canvas width and no more than 76 percent of height with wide completely empty margins. Background must be true transparent alpha. Everything beyond the single continuous outer silhouette is fully transparent; zero stray marks, zero white fringes, zero particles. No text or letters, no watermark, no mockup, no contact sheet, no background tile. Do not copy Notepad++, a chameleon, the Windows Notepad logo, or any other existing app branding. Use a compact open-book silhouette, not a spiral notepad.
```

## Verification

The selected PNG has a genuine alpha channel and transparent corner pixels. The PNG was inspected visually at source resolution, and the ICO directory and extracted small-size frames were checked after packaging. Earlier exploratory outputs are not app assets.
