# Objective-C lexer

`LexObjC.cxx` is copied byte-for-byte from the Lexilla subtree of Notepad++
8.9.8.1, not from Notepad++ application code. Its header identifies Neil Hodgson
(1998–2002), Don Ho's 2004 Objective-C modification, and the adjacent permissive
`License.txt`. That original license is included here and in runtime ZIPs.

- Source: https://github.com/notepad-plus-plus/notepad-plus-plus/blob/v8.9.8.1/lexilla/lexers/LexObjC.cxx
- SHA-256: `62c74fa9c9167a608f6321938fdd002bcc16c474df0bc1da01bc27355a3eba50`
- License: https://github.com/notepad-plus-plus/notepad-plus-plus/blob/v8.9.8.1/lexilla/License.txt
- License SHA-256: `ac32743bd464c837e481beae20df65a9207f84d3ff1912f6003000343e9c753d`

Lexilla 5.5.4 does not include this lexer. `tools/prepare_lexilla_languages.py`
adds it to a separately generated catalogue translation unit, while leaving
every file in the pinned official archives unchanged. The three compatibility
constants (SCLEX_OBJC 151, directive style 20, qualifier style 21) come from
the same tag's `lexilla/include/SciLexer.h` and are defined only for this extra
translation unit. Build receipts pin the original and generated bytes.
